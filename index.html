Zero-Knowledge Relay

The public gateway on health.syntropylabs.io acts solely as a client-side OAuth router. It possesses no database and never inspects or stores health tokens.

Standardized FHIR R4 normalizer that aggregates longitudinal lab trends, metabolic panels, vital signs, medications, and conditions into an actionable clinical view.

How Authorization Works

SMART on FHIR Standalone Patient Launch • RFC 7636 PKCE
1. Local instance initiates OAuth with PKCE challenge (S256)
2. Patient logs into Epic MyChart / Kaiser Permanente via encrypted TLS
3. Provider redirects to health.syntropylabs.io/callback (Zero-Knowledge Relay)
4. Browser instantly forwards authorization code to http://localhost:8000/callback
5. Local Python engine redeems code with PKCE verifier directly against FHIR server
